# EchoVR-Cosmetics-Editor
Cosmetics editor compiled in go, originally made by goopsie but modified by me to accept tint changes, title changes and emissive changes, please note this tool does not change how an emissive shows up in game, but it does change the colours that show on this emissive, what i mean by this is, it doesn't change the effect the emissive has.
